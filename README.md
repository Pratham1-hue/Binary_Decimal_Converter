# Binary Decimal Converter 🔁

A simple Python class that converts:
- Binary → Decimal
- Decimal → Binary

### 🚀 Example:

```python
from binary_decimal import Binary_Decimal

Binary_Decimal("1011", "binary")    # Decimal value: 11
Binary_Decimal(12, "decimal")       # Binary value: 1100
